# Bab 29. (Dihapus) Model C: Disk Dulu

**Bab ini dihapus pada Revisi 3.**

Isinya adalah Model C (instal ke disk dulu, lalu dipindahkan). Gunakan Bab 28 (instal langsung di ThinkCentre M710q).

Bila Proxmox suatu saat tidak mau boot, gunakan **Rescue Boot** dari menu USB installer (Advanced Options), seperti dijelaskan di Bab 8.2.
